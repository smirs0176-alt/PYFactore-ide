# Сервер-выключатель PyFactor

Что делает: IDE каждые 30 секунд спрашивает `GET /api/status`. Если ты отключил сервер, IDE показывает экран
«Произошла ошибка» с твоим сообщением, а когда включишь обратно, экран сам исчезает (проверка каждые 10 секунд).

## Запуск
    ADMIN_TOKEN=придумай-длинный-секрет-от-16-символов PORT=8080 go run .
Сборка: `go build -o pyfactor-server .` (в Windows — `go build -o pyfactor-server.exe .`). Готовые файлы в `dist/` лежат в репозитории, но в архив исходников релиза
не входят: их происхождение не проверено, поэтому собирай сервер сам.
В Windows: `set ADMIN_TOKEN=секрет` и затем `pyfactor-server.exe`.

## Управление
- **Телефон/браузер:** открой `http://адрес:8080/admin/`, введи токен, нажми большую кнопку.
- **Терминал (Node 18+):**
      set PYFACTOR_SERVER=http://адрес:8080
      set PYFACTOR_ADMIN_TOKEN=секрет
      node tools/switch.js off "Чиним баг, вернёмся через 10 минут"
      node tools/switch.js on
- **curl:** `curl -X POST адрес/api/admin/set -H "Authorization: Bearer СЕКРЕТ" -d '{"enabled":false,"message":"..."}'`

## В IDE
⚙ → «Сервер (адрес)…» → вставь адрес сервера. Если связи нет, IDE работает офлайн; чтобы блокировать и в этом
случае, поставь в `~/.pyfactor/settings.json` `"server_strict": true`.

## Настройки (переменные окружения)
| Переменная | Что делает |
|---|---|
| `ADMIN_TOKEN` | Токен администратора, **не короче 16 символов** (короче — сервер не запустится). Не задан — создаётся случайный и пишется в `admin_token.txt` рядом с `state.json` (права 0600); в лог он не попадает |
| `PORT`, `STATE_FILE` | Порт и файл состояния |
| `SECURE=1` | Сервер за HTTPS: добавляется заголовок HSTS |
| `TRUST_PROXY=1` | Сервер за nginx/Caddy: адрес клиента берётся из **последнего** значения `X-Forwarded-For` (его дописывает твой прокси) |

После 10 неверных попыток токена с одного адреса за 5 минут сервер отвечает 429, даже если дальше пришёл верный токен.
Токен принимается только в виде `Authorization: Bearer <токен>`. Тесты: `go test ./...`.

## Важно
- Токен ходит по сети: выставляй сервер за HTTPS (Caddy, nginx, Cloudflare Tunnel и т.п.), иначе токен можно подсмотреть.
- Состояние хранится в `state.json` (путь меняется переменной `STATE_FILE`) и переживает перезапуск.
