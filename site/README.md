# Сайт PyFactor

Регистрация и вход на сайте → кнопка «Скачать» → приложение при первом запуске **само подключается к аккаунту**.
Только стандартная библиотека Python 3.9+, ничего ставить не нужно.

## Файлы

- `server.py` — сервер и API
- `store.py` — база (аккаунты, сессии, устройства)
- `packager.py` — сборка архива приложения
- `index.html` — **весь сайт в одном файле**: разметка, стили и скрипт. Правишь его, перезагружаешь страницу, и всё. Оформление: ретро-терминал 90-х (зелёный экран ЭЛТ, DOS-окна, загрузка как в BIOS); кнопка «янтарь» в шапке переключает цвет экрана. Анимации отключаются, если в системе включено «уменьшить движение».

## Запуск

    python site/server.py

Открой http://127.0.0.1:8081, создай аккаунт, нажми «Скачать PyFactor».
Распакуй архив и запусти `scripts/run.bat` (Windows) или `scripts/run.sh`: IDE откроется уже под твоим аккаунтом.

## Как работает подключение

1. Кнопка «Скачать» создаёт **одноразовый код** (действует 7 дней) и кладёт его в архив, в файл `PyFactor/connect.json`.
2. При запуске приложение отправляет код на сайт (`/api/device/claim`) и получает долгий **токен устройства**.
3. Токен хранится в `~/.pyfactor/settings.json`, а `connect.json` удаляется. Код после этого больше не работает.
4. При каждом запуске приложение в фоне проверяет токен. Если устройство отключили на сайте (раздел «Мои устройства»), приложение просит войти заново.
5. «Выйти» в приложении отключает это устройство и на сайте.

В базе (`site/data/site.db`) нет открытых паролей и токенов: пароли — PBKDF2-SHA256 с солью (600 000 кругов; у старых аккаунтов 240 000, при следующем входе хеш сам обновляется), сессии, коды и токены — только хеши.

## Настройки (переменные окружения)

| Переменная | Что делает |
|---|---|
| `SITE_HOST`, `SITE_PORT` | Адрес и порт (по умолчанию `127.0.0.1:8081`) |
| `SITE_URL` | Публичный адрес, например `https://pyfactor.example.com`. Он попадает в `connect.json` |
| `SITE_SECURE=1` | Сайт работает по HTTPS: cookie получает флаг Secure, включается HSTS |
| `SITE_TRUST_PROXY=1` | Сайт стоит за nginx/Caddy: адрес клиента берётся из **последнего** значения `X-Forwarded-For` (его дописывает твой прокси), плюс `X-Forwarded-Proto`. Прокси должен дописывать адрес, а не пропускать чужой заголовок без изменений |
| `SITE_DATA` | Папка с базой (по умолчанию `site/data`) |
| `RESEND_API_KEY` | Включает подтверждение почты кодом при регистрации |
| `RESEND_FROM` | Адрес отправителя. Без него Resend шлёт только владельцу своего аккаунта |

## Выложить в интернет

Python-сервер сам не умеет HTTPS. Поставь перед ним Caddy или nginx с сертификатом и запускай так:

    SITE_URL=https://pyfactor.example.com SITE_SECURE=1 SITE_TRUST_PROXY=1 RESEND_API_KEY=re_... RESEND_FROM=noreply@example.com python site/server.py

Приложение отказывается подключаться по обычному `http://`, если сайт не в локальной сети: токен нельзя гонять открытым текстом.

## Чего пока нет

- Сброса пароля по почте.
- Смены пароля и удаления аккаунта.
- Вход в приложении по email и паролю с сайта (сейчас подключение идёт только через скачанный архив).
- Ограничения лимитов хранятся в памяти: после перезапуска сервера они сбрасываются.
