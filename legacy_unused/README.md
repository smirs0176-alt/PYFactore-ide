# legacy_unused

Старые плоские копии модулей, которые лежали рядом с новыми пакетами (`core/languages/`, `features/workspace/` и т. д.).
Приложение их не импортирует: проверено графом импортов от `pyfactor/__main__.py`, тестами и сборкой.
Часть файлов отличается от живых версий (в живых уже есть исправления безопасности), поэтому их **нельзя** возвращать в `pyfactor/`.
Если всё работает — папку можно удалить целиком.
